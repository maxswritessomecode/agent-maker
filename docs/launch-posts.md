# Launch Posts

## GitHub Description

Recommend agents based on the work you already do.

## Short Pitch

Agent Maker helps you figure out which AI agents are worth building. It looks at approved, read-only work signals, finds repeated tasks and reasoning workflows, then drafts safe agent proposals with evidence, boundaries, and scaffold specs.

## Show HN Draft

```text
Show HN: Agent Maker, a skill that recommends which AI agents to build

Most agent builders start with "describe the agent you want."

I wanted the step before that: look at the work someone already does, find repeated workflows, and recommend the 1-3 agents actually worth building.

Agent Maker is an installable skill. It works metadata-first, read-only, and draft-only. It produces Markdown proposals and scaffold specs for agent runtimes like Codex/Claude skills, Copilot-style custom agents, Zapier, Gumloop, or n8n.

The safety boundary is the product: no employee monitoring, no regulated decisions, no autonomous actions, no broad permission requests.
```
