# GitHub Launch Plan

## Positioning

Short pitch:

> Agent Maker recommends safe AI agent candidates from approved work context.

Longer pitch:

> Most agent builders ask users to describe the agent they want. Agent Maker starts earlier: it reviews approved read-only work context, identifies recurring workflows, and drafts safe, reviewable agent proposals before anything is activated.

## Launch Checklist

- Choose a license before public release, then add `LICENSE` and package metadata.
- Add a 90-second GIF or screenshot walkthrough.
- Add one anonymized sample export and generated proposal.
- Add "Install as a skill" and "First 5 minutes" instructions at the top of the README.
- Add a short demo issue: "Use this sample metadata to recommend agents."
- Pin the repo in the GitHub profile after publishing.
- Submit to relevant skill/agent directories if appropriate.
- Add GitHub repo description: "Recommend safe AI agent candidates from approved work context."
- Add topics from the suggested topic list.

## Launch Copy

```text
I built Agent Maker, a skill that helps you figure out which AI agents you should build.

Most agent builders start with: "Describe the agent you want."

Agent Maker starts earlier:
1. Look at approved work context
2. Find repeated tasks and reasoning workflows
3. Recommend the top 1-3 AI coworkers
4. Draft safe agent specs with permissions, boundaries, and output folders

No Python required for normal use. It works as an installable skill.
```

## 30/60/90 Plan

30 days:

- publish README, demo, safety docs, and sample outputs
- post to Show HN and one founder/build thread
- ask 10 target users to run it on approved context or local exports
- target: 100 stars and 15 install attempts

60 days:

- add persona examples for PM, founder/operator, consultant, support lead, engineering lead
- add screenshot or GIF walkthrough
- submit to AI tool directories and skill lists
- target: 200 stars and 5 detailed feedback issues

90 days:

- publish a comparison article: agent discovery versus agent builders
- add one complete proposal-to-installed-skill path
- launch Product Hunt only if activation evidence is real
- target: 300 stars and 10 scaffold specs generated by users
