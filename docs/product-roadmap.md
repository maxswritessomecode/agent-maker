# Product Roadmap

## Phase 1: GitHub Conversion

- Show a no-Python skill workflow first.
- Add sample outputs by persona.
- Publish privacy, security, and safety docs.
- Make the optional CLI copy-paste runnable.
- Add a demo screenshot or GIF.

## Phase 2: Activation

- Improve opportunity scorecards.
- Add troubleshooting for thin context, noisy context, and sensitive sources.
- Add role-specific prompt recipes.
- Add scaffold renderers for Codex Skills and Claude Skills.

## Phase 3: Retention

- Add an agent backlog output: accepted, rejected, deferred, needs evidence.
- Add proposal comparison across runs.
- Add eval packs for generated agents.
- Add team-shared examples once safety and permissions are well understood.

## North Star

Reviewed agent proposals generated from approved context.

## Leading Indicators

- first prompt copied
- skill installed
- source scope selected
- first proposal generated
- proposal kept, revised, or discarded
- scaffold spec generated
