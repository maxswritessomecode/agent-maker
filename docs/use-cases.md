# Use Cases

## Product Manager

Pattern: recurring launch syncs, stakeholder updates, ticket reviews, and decision docs.

Likely agents:

- Status Update Assistant
- Decision Memo Partner
- Meeting Follow-up Coordinator

## Founder Or Operator

Pattern: repeated follow-ups, investor/customer prep, hiring-adjacent admin that must avoid evaluation decisions, and weekly operating updates.

Likely agents:

- Open-Loops Tracker
- Account Briefing Assistant
- Weekly Operating Update Assistant

## Consultant

Pattern: client meetings, notes, deliverable drafts, research memos, and project recaps.

Likely agents:

- Client Briefing Assistant
- Decision Memo Partner
- Deliverable Review Assistant

## Support Or Customer Success Lead

Pattern: account notes, customer threads, support escalations, and handoff summaries.

Likely agents:

- Account Briefing Assistant
- Escalation Summary Assistant
- Follow-up Drafting Assistant

## Engineering Lead

Pattern: tickets, PRs, release notes, incidents, project updates, and planning docs.

Likely agents:

- Release Notes Assistant
- Project Status Assistant
- Incident Follow-up Assistant
