# Comparison

Agent Maker is an upstream discovery layer. It helps decide which agent should exist before the user spends time in an agent builder.

| Category | Strength | Limitation | Agent Maker's role |
|---|---|---|---|
| Custom GPTs and assistant builders | Fast to create known assistants | User must know what to build | Finds high-value agent candidates |
| Codex or Claude Skills | Powerful reusable workflows | Require clear instructions | Drafts skill specs and boundaries |
| Zapier, Gumloop, n8n | Strong workflow automation | Best when triggers/actions are known | Identifies safe workflows first |
| Productivity copilots | Good for one-off work | Less reusable by default | Converts repeated work into proposals |
| Process mining tools | Great for system logs | Heavyweight and enterprise-oriented | Lightweight user-level discovery |

## Differentiator

Agent Maker combines:

- approved-context discovery
- metadata-first source review
- opportunity scorecards
- safety boundaries
- human-reviewed scaffold specs

It should complement agent builders, not replace them.
